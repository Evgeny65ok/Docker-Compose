# 🐳 Лабораторная работа: Развертывание Homehub через Docker Compose

**Homehub** — это универсальная семейная панель управления. Лёгкое веб-приложение для домашней сети, включающее в себя заметки, списки покупок, домашние дела, загрузку медиафайлов, отслеживание расходов и многое другое.  
**Исходный код проекта:** [github.com/surajverma/homehub](https://github.com/surajverma/homehub)  
**Локальный порт:** `5000`  

---

## 🏗️ 1. Описание проекта и конфигурация

Для выполнения работы официальный репозиторий Homehub был склонирован из апстрима (`git clone`). 

В корне проекта подготовлен файл конфигурации `compose.yaml`, описывающий сборку приложения, а также конфигурационный файл `config.yml`, который задает название инстанса, список членов семьи, доступные модули и тему оформления. Пользовательские данные изолированы и сохраняются в локальных папках проекта.

### 📂 Структура проекта

```text
homehub/
├── compose.yaml  # Конфигурационный файл Docker Compose
├── config.yml    # Настройки модулей и интерфейса Homehub
├── README.md     # Документация лабораторной работы
├── uploads/      # Папка для загруженных файлов
├── media/        # Медиафайлы
├── pdfs/         # Документы PDF
├── data/         # База данных и системные файлы
├── 1.png         # Скриншоты для отчета
├── 2.png
└── 3.png
```

## 🚀 2. Запуск контейнера в Docker

Сборка образа и запуск контейнера выполнены в фоновом режиме с помощью команды:

```bash
docker compose up -d
```

## 🧩 4. Работа с модулями
