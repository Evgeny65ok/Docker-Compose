# 🐳 Лабораторная работа: Развертывание PostgreSQL + pgAdmin через Docker Compose

**СУБД:** PostgreSQL 17-alpine  
**Веб-клиент:** pgAdmin 4  
**Локальный порт PostgreSQL:** `5432`  
**Локальный порт pgAdmin:** `5050`  

---

## 🏗️ 1. Описание проекта и конфигурация

Для выполнения работы создан конфигурационный файл `compose.yaml` (структура проекта: `postgresql-pgadmin/compose.yaml`). 

Файл описывает два сервиса:
* **`postgres`** — СУБД PostgreSQL 17 на базе легковесного образа Alpine.
* **`pgadmin`** — официальный веб-клиент pgAdmin 4 для удобного управления базой через браузер.

Данные базы данных изолированы и сохраняются в именованном томе `postgres_data`.

---

## 🚀 2. Запуск контейнеров в Docker

Запуск контейнеров выполнен в фоновом режиме:

```bash
docker compose up -d
```

Веб-интерфейс pgAdmin доступен в браузере по адресу: [http://localhost:5050](http://localhost:5050).

| :--- | :--- |

## 🗄️ 4. Работа с базой данных

Для управления созданной СУБД внутри веб-интерфейса pgAdmin регистрируется новый сервер. Используйте следующие параметры подключения:

| Параметр подключения | Значение |
| :--- | :--- |
| **Host name / Address** | `postgres-db` |
| **Port** | `5432` |
| **Maintenance database**| `mydatabase` |
| **Username** | `myuser` |
