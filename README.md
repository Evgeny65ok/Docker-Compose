# 🐳 Docker Compose Projects

Коллекция учебных лабораторных работ по быстрому развёртыванию популярных сервисов, веб-приложений и современных СУБД с помощью инструментов **Docker Compose**. 

Каждый проект полностью изолирован в собственной директории, содержит индивидуальный конфигурационный файл `compose.yaml`, подробную инструкцию по запуску `README.md` и скриншоты подтверждения работоспособности.

## 🚀 Быстрый старт

Для запуска любого выбранного проекта перейдите в его рабочую директорию и поднимите контейнеры в фоновом режиме:

```bash
cd <имя-проекта>
docker compose up -d
```

### 🛠️ Полезные команды для мониторинга:

* **Проверка текущего статуса и портов:**
  ```bash
  docker compose ps -a
  ```
* **Просмотр логов в реальном времени:**
  ```bash
  docker compose logs -f
  ```
* **Остановка работы сервисов (без удаления данных):**
  ```bash
  docker compose stop
  ```
* **Полное удаление контейнеров и связанных томов (Volumes):**
  ```bash
  docker compose down -v
  ```

## 🧰 Системные требования

* Установленный **Docker Desktop** (или связка Docker Engine + плагин Docker Compose v2).
* Свободные локальные порты на хост-машине: `3000`, `5000`, `5050`, `5173`, `5432`, `8081`, `8082`, `8083`, `8978`.
* Минимум **10 ГБ свободного места** на диске для кэширования и загрузки официальных Docker-образов.

## 📖 Краткое описание проектов

### 1. Joomla
Связка CMS Joomla и базы данных MariaDB. Используется для быстрого развёртывания блогов и корпоративных сайтов. Доступ: **порт 8082**.

### 2. WordPress
Классическая инфраструктура для работы самой популярной CMS. Контейнер приложения связан с изолированной базой данных MySQL 8.0. Доступ: **порт 8081**.

### 3. MySQL + phpMyAdmin
Готовая среда разработки, включающая СУБД MySQL 8.0 и веб-панель phpMyAdmin, заменяющую тяжеловесные десктопные клиенты. Доступ к панели: **порт 8083**.

### 4. PostgreSQL
Одиночный контейнер объектно-реляционной СУБД PostgreSQL 15. Включает механизм `healthcheck` для автоматического контроля доступности и скрипт первичной инициализации таблиц. Доступ: **порт 5432**.

### 5. PostgreSQL + pgAdmin
Стек из современной СУБД PostgreSQL 17 и мощного веб-инструмента администрирования pgAdmin 4 для управления схемами и выполнения сложных аналитических запросов. Доступ к pgAdmin: **порт 5050**.

### 6. drawDB
Браузерный визуальный инструмент для проектирования архитектуры баз данных и связей между таблицами с последующим экспортом готового SQL-кода. Собран из официальных исходников. Доступ: **порт 5173**.

### 7. LibreDB Studio
Универсальная веб-IDE («браузерный DataGrip / DBeaver»), разворачиваемая прямо в сети баз данных и обеспечивающая единый интерфейс управления для PostgreSQL, MySQL и SQLite. Доступ: **порт 3000**.

### 8. Homehub
Полноценный легковесный органайзер для домашнего использования. Содержит встроенные модули контроля задач, списков продуктов, финансов и хранения документов. Доступ: **порт 5000**.

### 9. CloudBeaver
Полноценная облачная альтернатива DBeaver, развернутая через официальный образ. Предоставляет расширенный веб-интерфейс для написания SQL-запросов и мониторинга таблиц. Доступ: **порт 8978**.
