# 🚀 Joomla в Docker Compose

**Joomla!** — это современная CMS с открытым исходным кодом, написанная на PHP и JavaScript. В качестве системы управления базами данных используется стек MySQL / MariaDB.

Этот репозиторий содержит готовый конфигурационный файл для быстрого локального развертывания платформы с помощью Docker Compose.

---


## ⚡ Быстрый запуск

1. Поднимите контейнеры в фоновом режиме:
   ```bash
   docker compose up -d
   ```

2. Убедитесь, что все сервисы успешно запустились:
   ```bash
   docker compose ps -a
   ```

---

## 🌐 Доступ к платформе

После успешного старта контейнеров веб-интерфейсы будут доступны по следующим адресам:

* 🏠 **Главная страница сайта:** [http://localhost:8082](http://localhost:8082)
* ⚙️ **Панель администратора:** [http://localhost:8082/administrator](http://localhost:8082/administrator)

## 🔑 Параметры подключения к БД

При первом входе запустится мастер настройки Joomla. Используйте следующие конфигурационные данные для подключения к базе данных:

| Параметр | Значение |
| :--- | :--- |
| **Тип базы данных** | `MySQLi` |
| **Имя сервера (Хост)** | `db` |
| **Имя пользователя** | `joomla_user` |
| **Пароль** | `joomla_password` |
| **Имя базы данных** | `joomla_db` |

## 🛠️ Управление контейнерами

Основные команды для администрирования развернутого окружения:

| Действие | Команда |
| :--- | :--- |
| **Просмотр логов Joomla** | `docker compose logs -f joomla` |
| **Просмотр логов БД** | `docker compose logs -f db` |
| **Остановка сервисов** | `docker compose stop` |
| **Запуск остановленных сервисов** | `docker compose start` |
| **Перезапуск контейнеров**| `docker compose restart` |
| **Проверка конфигурации** | `docker compose config` |

---

## 🗑️ Удаление проекта

Если вам необходимо полностью удалить окружение, включая сохраненные данные в Docker Volumes и файлы проекта, выполните:

```bash
# Останавливаем контейнеры и удаляем связанные Volumes
docker compose down -v

# Удаляем директорию проекта
cd .. && rm -rf joomla
```
