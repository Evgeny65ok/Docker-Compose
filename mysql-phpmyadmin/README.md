# 🐳 Лабораторная работа: Развертывание MySQL + phpMyAdmin через Docker Compose

**СУБД:** MySQL 8.0  
**Веб-клиент:** phpMyAdmin (latest)  
**Локальный порт phpMyAdmin:** `8083`  
**Локальный порт MySQL:** `3306`  

---

## 🏗️ 1. Описание проекта и конфигурация

Для выполнения работы создан конфигурационный файл `compose.yaml` (структура проекта: `mysql-phpmyadmin/compose.yaml`). 

Файл описывает два изолированных сервиса:
* **`mysql`** — база данных на базе MySQL 8.0.
* **`phpmyadmin`** — веб-интерфейс для управления СУБД.

Сервисы объединены в общую виртуальную сеть `mysql-pma-network`. Также настроен постоянный том (Volume) для сохранения данных базы при перезапуске контейнеров.

---

## 🚀 2. Запуск контейнеров в Docker

Запуск контейнеров выполнен в фоновом режиме с помощью команды:

```bash
docker compose up -d
```

## 🖥️ 3. Доступ к phpMyAdmin

## 🗄️ 4. Работа с базой данных

Внутри phpMyAdmin доступна база данных **`my_database`**, созданная автоматически при старте контейнера MySQL. Через веб-интерфейс можно полноценно управлять таблицами, выполнять SQL-запросы, а также производить экспорт и импорт дампов.
