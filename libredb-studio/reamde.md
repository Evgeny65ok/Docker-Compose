# 🐳 Лабораторная работа: Развертывание LibreDB Studio через Docker Compose

**LibreDB Studio** — это открытая (MIT) веб-IDE для полноценной работы с базами данных. Она разворачивается как контейнер в Docker рядом с целевыми СУБД, выступая в роли веб-аналога DataGrip или DBeaver. Предоставляет единую точку входа для выполнения запросов, визуализации данных и администрирования инфраструктуры.

**Локальный порт веб-интерфейса:** `3000`

---

## 🏗️ 1. Описание проекта и конфигурация

Для выполнения работы подготовлен файл конфигурации `compose.yaml` (находится в корне: `libredb-studio/compose.yaml`) и файл конфигурации окружения `.env` с обязательными секретами для инициализации приложения (`ADMIN_EMAIL`, `ADMIN_PASSWORD`, а также `JWT_SECRET` длиной не менее 32 символов). Данные настроек студии изолированы и сохраняются в именованном Docker Volume `libredb-data`.

### 📂 Структура проекта

```text
libredb-studio/
├── compose.yaml   # Конфигурационный файл Docker Compose
├── .env           # Секреты и переменные окружения
├── README.md      # Документация лабораторной работы
├── 1.png          # Скриншоты для отчета
├── 2.png
└── 3.png
```

## 🚀 2. Запуск контейнера в Docker

Инициализация сервисов и запуск веб-студии выполнены в фоновом режиме с помощью стандартной команды:

```bash
docker compose up -d
```

## 🖥️ 3. Веб-интерфейс LibreDB Studio

Веб-панель управления доступна в браузере по адресу: [http://localhost:3000](http://localhost:3000).

### Данные для авторизации администратора:

| Параметр | Значение |
| :--- | :--- |
| **Логин** | `admin@libredb.org` |
| **Пароль** | `YourStrongPassword123!` |

После успешного входа открывается административный дашборд с индикаторами здоровья системы, количеством активных сессий, метриками размера БД и общим списком подключённых источников данных.

## 🗄️ 4. Работа с базой данных

Через встроенный веб-редактор можно настраивать новые подключения к популярным СУБД (PostgreSQL, MySQL, SQLite и др.), выполнять произвольные SQL-запросы и визуализировать возвращаемые результаты. Для быстрого ознакомления с функционалом в системе сразу доступны демонстрационные базы `Sample (Employees)` и `Sample (LibreDB)`.
