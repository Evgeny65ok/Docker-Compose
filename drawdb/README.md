# 🐳 Лабораторная работа: Развертывание drawDB через Docker Compose

**drawDB** — бесплатный, простой и интуитивно понятный инструмент для проектирования ER-диаграмм (схем баз данных) и автоматической генерации SQL прямо в браузере.  
**Исходный код проекта:** [github.com/drawdb-io/drawdb](https://github.com/drawdb-io/drawdb)  
**Локальный порт:** `5173`  

---

## 🏗️ 1. Описание проекта и конфигурация

Для выполнения работы официальный репозиторий drawDB был склонирован из апстрима (`git clone`). В корневой директории проекта подготовлен файл конфигурации `compose.yaml`, описывающий сборку приложения и запуск веб-редактора в изолированном контейнере.

### 📂 Структура проекта

```text
drawdb/
├── compose.yaml  # Конфигурационный файл Docker Compose
├── README.md     # Документация и описание лабораторной работы
├── 1.png         # Скриншоты работы приложения для отчета
├── 2.png
└── 3.png
```

---

## 🚀 2. Запуск контейнера в Docker

Сборка образа и запуск веб-редактора выполнены в фоновом режиме с помощью команды:

```bash
docker compose up -d
```

## 🖥️ 3. Веб-интерфейс drawDB

Веб-приложение доступно в браузере по адресу: [http://localhost:5173](http://localhost:5173).  
На главной странице интерфейса можно сразу приступить к созданию новой диаграммы с нуля или выбрать готовый демонстрационный шаблон.

## 🗄️ 4. Редактор ER-диаграмм

В интерактивном веб-редакторе реализована полноценная визуализация сущностей: создание таблиц, настройка связей (один-ко-многим, многие-ко-многим), добавление индексов и ключей. Готовую схему можно в один клик экспортировать в виде SQL-скрипта для популярных СУБД (PostgreSQL, MySQL, SQLite, Oracle и др.).
