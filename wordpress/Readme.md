## 🏗️ 1. Описание проекта и конфигурация

Для выполнения работы в каталоге проекта был создан конфигурационный файл `compose.yaml` (структура проекта: `wordpress/compose.yaml`). Файл описывает два изолированных сервиса (`db` на базе MySQL и `wordpress`), объединенных в общую виртуальную сеть `wp-network`. Также настроены постоянные тома (volumes) для сохранения данных базы и контента сайта.

## 🚀 2. Запуск контейнеров в Docker

Запуск многоконтейнерного окружения был выполнен в фоновом режиме с помощью встроенного плагина Docker CLI.
Команда запуска:
```bash
docker compose up -d
```
