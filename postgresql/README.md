# 🐳 Лабораторная работа: Развертывание PostgreSQL через Docker Compose

**СУБД:** PostgreSQL 15  
**Локальный порт:** `5432`  

---

## 🏗️ 1. Описание проекта и конфигурация

Для выполнения работы создан конфигурационный файл `compose.yaml` (структура проекта: `postgresql/compose.yaml`). 

Файл описывает сервис **`postgres`** на базе официального образа PostgreSQL 15 с настроенным автоматическим контролем работоспособности (`healthcheck`). Данные базы данных сохраняются локально в папку `./data`, а при самом первом запуске автоматически выполняется SQL-скрипт инициализации `scripts/init.sql`.

### 📂 Структура проекта

```text
postgresql/
├── compose.yaml      # Файл конфигурации Docker Compose
├── README.md         # Описание проекта и инструкции
├── data/             # Локальная папка для хранения данных БД
├── scripts/          # Скрипты инициализации
│   └── init.sql      # SQL-скрипт создания начальной схемы
├── backups/          # Папка для резервных копий
├── 1.png             # Скриншоты для отчета
├── 2.png
└── 3.png
```

## 🚀 2. Запуск контейнера в Docker

Запуск контейнера выполнен в фоновом режиме:

```bash
docker compose up -d
```

## 🗄️ 3. Подключение к базе данных

Интерактивное подключение к СУБД через утилиту `psql` прямо внутри контейнера:

```bash
docker exec -it my-postgres psql -U myuser -d mydatabase
```

При автоматической инициализации контейнера создаются следующие сущности:
* **База данных:** `mydatabase`
* **Пользователь:** `myuser`
* **Таблица:** `users` (сразу заполняется двумя тестовыми записями)
